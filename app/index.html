What is and isn't measured

The Windows collector reads the foreground application, Windows system idle time and occasional cursor positions in memory to calculate movement samples. It never saves the positions. It does not record clicks, actual keystrokes or browser URLs. Claude Code and Codex inside a terminal or editor are generally counted under that host app until dedicated integrations are added. Manual work sessions are separate and are not added to automatic screen time totals.
